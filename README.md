# Palpites API (GitHub Pages)

API estática em JSON para hospedar no GitHub Pages.

## Endpoints

- `/palpites.json` — JSON completo
- `/palpites-todos-os-jogos.json` — alias do JSON completo
- `/palpite/{participante}.json` — palpites de um participante
- `/jogo/{jogo}.json` — palpites de um jogo
- `/endpoints.json` — mapa com todos os endpoints gerados

## Exemplos

- `/palpite/paloma.json`
- `/palpite/ricardo-nunes.json`
- `/palpite/bruno-nobrega.json`
- `/jogo/argentina-x-austria.json`
- `/jogo/noruega-x-senegal.json`
